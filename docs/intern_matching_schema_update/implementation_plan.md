# 実装計画: 求人・応募管理機能のUI改善および追加要件

## 目的
ユーザーから寄せられた追加の修正要望（学生向けの求人一覧の表形式化、企業向けの応募者管理の統合とカレンダー入力、ログイン画面のUI変更、管理者向けの応募者情報表示）を実装し、プラットフォームの使い勝手と一覧性を向上させる。

## 実装内容の詳細

### 1. 学生ロール: 求人一覧 (`/student/jobs/page.tsx`)
- **表形式（Table）への変更**: 現在のカード形式の表示から、一覧性の高い表（Table）形式に変更する。
- **表示項目**: 企業名、職種、実施期間、受入人数、実施形態、就業場所、報酬など。
- **ソートとフィルタリングUI**: 表の各カラムヘッダー（一番上のラベル）に、アイコンを配置し、クリックでソートやフィルタリングのメニューが開くようにする。
- **複数条件フィルタリング**: 既存のフィルタ状態（複数条件）を維持しつつ、UIをモダンなテーブルヘッダー型に移行する。

### 2. 企業ロール
#### 求人登録 (`company/jobs/new/page.tsx`, `company/jobs/[id]/edit/page.tsx`)
- **実施期間のカレンダー入力**: `periodStart` と `periodEnd` の入力フィールドを単なる文字列（Input）から、カレンダーピッカー（`type="date"` または専用コンポーネント）を利用した選択方式に変更する。

#### 求人詳細・応募管理 (`company/jobs/[id]/page.tsx`)
- **応募者管理の統合**: 既存の「応募者管理」専用画面を廃止し（ナビゲーション等から削除）、求人詳細画面の下部に応募者リストを集約する形式を採用する。
- **アクションボタンとモーダル**: 応募者の行（またはカード）の脇に、「詳細・面談日設定」モーダルを開くボタンを配置する。
- **面談日のカレンダー入力**: モーダル内の面談日設定フィールドを単なるテキスト入力から、カレンダー入力（`type="datetime-local"` 等）に変更する。
- **インターン管理画面へのリンク**: マッチングが成立（`matched`）した学生に対し、個別のインターン管理画面（`/company/intern/[matchId]`）へ遷移するボタンを追加する。

### 3. 未ログイン/共通ロール (`/login/page.tsx`)
- **「企業の方はこちら」の常時表示**: アコーディオン（トグル）で隠れている企業のログインフォームを初期状態から展開し、常時表示するレイアウトに変更する。

### 4. 管理者ロール (`/admin/jobs/page.tsx`, 等)
- **求人管理画面への応募者情報表示**: 求人管理一覧（または詳細モーダル内）に、その求人に対して承認済みの学生（応募者）の名前を表示する。
- **面談日の表示**: 企業が面談日を設定している場合、その面談日も管理者から確認できるように表示を追加する。具体的には、承認済みアプリケーションの取得処理を `admin/jobs/page.tsx` に追加するか、求人詳細の Modal 内に応募者一覧セクションを設ける。
