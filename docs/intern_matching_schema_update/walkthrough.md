# 修正内容の確認 (Walkthrough)

追加要件に基づくUI改善と新機能の実装が完了しました。以下の手順で変更内容をご確認いただけます。

## 1. 学生ロール: 求人一覧の表形式化
- **対象画面:** 学生ログイン後 ＞ `求人検索` (`/student/jobs`)
- **確認事項:**
  - 求人一覧が従来のカード形式から、一覧性の高い表（テーブル）形式に変更されていること。
  - テーブルのヘッダーに「職種」「実施形態」「報酬」の絞り込み（フィルタリング）用セレクトボックスが配置されていること。
  - 「実施期間」のヘッダーをクリックすると、「開始時期が早い順」と「新着順」のソートが切り替わること。
  - キーワード検索とこれらのフィルタリングが複合して正しく動作し、絞り込まれた結果が表示されること。

## 2. 企業ロール: 求人登録・編集のカレンダー入力
- **対象画面:** 企業ログイン後 ＞ `自社求人管理` ＞ `新規求人作成` または `編集`
- **確認事項:**
  - 「基本情報」セクション内の「実施期間 (開始)」および「実施期間 (終了)」の入力フィールドが、カレンダーアイコン付きの日付ピッカー (`type="date"`) になっていること。
  - カレンダーから日付を選択して保存できること。

## 3. 企業ロール: 応募管理機能の統合と面談日設定
- **対象画面:** 企業ログイン後 ＞ `自社求人管理` ＞ 各求人の `詳細` (`/company/jobs/[id]`)
- **確認事項:**
  - 画面下部に「応募者一覧」セクションが追加され、その求人にエントリーした学生の一覧が表示されること。
  - 各応募者の「詳細・面談日設定」ボタンをクリックするとモーダルが開き、学生の詳細情報とともに「面談日の設定」フィールドが表示されること。
  - 面談日の設定入力が日時ピッカー (`type="datetime-local"`) になっており、カレンダーと時間を使って選択・保存ができること。
  - ステータスが「マッチング成立（matched）」になった学生の項目に、「インターン管理（インターン管理画面へのリンク）」ボタンが表示されること。
  - サイドバーから独立した「応募者管理」メニューがなくなり、`/company/applicants` 画面が削除されていること。

## 4. ログイン画面のUI改修
- **対象画面:** 未ログイン状態 ＞ `ログイン画面` (`/login`)
- **確認事項:**
  - 「企業の方はこちら」の入力フォームが、初期状態から常にアコーディオンが開いた状態（常時表示）になっていること。
  - トグルのための開閉アイコンがなくなっていること。

## 5. 管理者ロール: 応募者情報・面談日の表示
- **対象画面:** 管理者ログイン後 ＞ `求人承認` (`/admin/jobs`) ＞ 任意の求人の `詳細確認`
- **確認事項:**
  - 開いた求人詳細モーダルの下部に「応募状況」セクションが追加されていること。
  - その求人に実際に応募している学生の「氏名」、「応募日」、および企業側で設定した「面談日」が一覧で表示されること。
