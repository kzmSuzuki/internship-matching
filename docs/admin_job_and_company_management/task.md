# タスク

1. **求人内のラベル変更**
   - 「想定アウトプット」を「期待する成果・想定アウトプット」に名称変更。
2. **求人項目への交通費・宿泊費の有無の追加**
   - 新規求人作成や編集、閲覧画面に「交通費の支給」「宿泊費の支給」の有無を追加する。
3. **管理者ロールでの取り消し機能追加**
   - 「求人の取り消し」「求人への学生の応募の取り消し」「企業のオファーの取り消し」「学生のオファー承諾の取り消し」機能を実装し、ステータスを強制的に取り消し(closedやcancelled)にできるようにする。
4. **企業プロフィール画面での文言追加**
   - 初回ログイン・編集画面へ、「承認されてから、求人を作成ください。問題がある場合はinternship@xxxx.jpに連絡をお願いします」という案内を追記する。
5. **学生側の求人詳細での注意書き追加**
   - 「応募済み」または「他の求人に応募中」で再応募不可になっている状態の際、下に赤文字で「間違って応募した場合はinternship@xxxx.jpに連絡をお願いします」という注意書きを追加する。
